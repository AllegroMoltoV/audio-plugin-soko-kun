My Gain
=======

Changes the level of a stereo signal. VST® 3 and CLAP formats for Windows x64 and Linux x86_64.

Source code and verification:
  https://github.com/your-account/my-gain-audio

Install
-------

1. Close your DAW.
2. Windows: copy the folder "VST3\My Gain.vst3" to %LOCALAPPDATA%\Programs\Common\VST3\ (only you)
   or C:\Program Files\Common Files\VST3\ (all users, needs administrator).
3. Windows, for CLAP hosts: copy "CLAP\My Gain.clap" to %LOCALAPPDATA%\Programs\Common\CLAP\
   or C:\Program Files\Common Files\CLAP\.
4. Linux: copy the folder "VST3/My Gain.vst3" to ~/.vst3/ and "CLAP/My Gain.clap" to ~/.clap/.
5. Start your DAW and rescan plug-ins if needed.

No installer and no network access. The plug-in does not send any audio or data anywhere.
