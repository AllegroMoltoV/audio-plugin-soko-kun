Web カタログの画面の一覧と、各画面に置く要素の仕様です。Web カタログは閲覧専用で、プラグインの登録は MCP の `submit_plugin` だけで受け付けます。

画面の骨組みは配信プラグイン倉庫くんの [画面構成](https://github.com/AllegroMoltoV/plugin-soko-kun/blob/main/docs/design/ui.md) を引き継ぎ、次の 3 点を変えています。

- 規格・OS・アーキテクチャを、配布物の中身の検査の結果から表示する
- VST の語を、Steinberg VST usage guidelines の文面にしたがって表示する ([ADR 0004](../decisions/0004-vst-trademark.md))
- カテゴリと文言を、オーディオプラグインの語に替える

## 共通の仕様

| 項目 | 仕様 |
| --- | --- |
| スクリプト | 使わない。検索はフォームの送信で行う |
| 出力の無害化 | Hono の JSX の自動エスケープを使い、生の HTML を出力しない |
| 応答ヘッダー | `Content-Security-Policy` は `default-src 'none'` を基本とし、スタイルシートと画像とフォームの送信先を自サイトに限る。`X-Content-Type-Options: nosniff`・`Referrer-Policy: strict-origin-when-cross-origin`・`X-Frame-Options: DENY` を付ける |
| プラグインの名前 | 宣言ファイルの `name` を表示する。無ければリポジトリ名を表示する。外部データとして扱う |
| 外部データ | 概要は画面の言語へ機械翻訳して表示し、自動翻訳である旨を添える。詳細ページには原文を表示するリンクも添える。配布物名は GitHub の原文のまま表示する。リリース名とアーカイブの中のファイル名は画面に出さない |
| 示す版 | 掲載対象バージョンだけを示す。それより新しく検査済みでないリリースは示さない |
| 示す配布物 | 案内する配布物だけを示す。インストーラーと案内しない配布物は示さない |
| 掲載の範囲 | 一覧に出すのは掲載中のプラグインだけ |
| モバイル表示 | 幅 760 px 以下で 1 段組みに切り替える。幅 320 px まで、画面の右端からはみ出す要素を作らない |
| スクロール | 画面全体の縦方向のスクロールだけを使う。要素の中のスクロールと横方向のスクロールは使わない |

## 見た目の方針

配置・文字の大きさ・罫線・ボタン・暗い配色の切替え・コントラスト比の規則は、配信プラグイン倉庫くんと同じにします。2000 年代前半のソフトウェア紹介サイトの見た目です。

テーマカラーは、主の色を `#20256e`、副の色を `#e2c69c` にします。副の色は配信プラグイン倉庫くんと共通で、主の色を配信プラグイン倉庫くんの赤紫と替えて、2 つのサービスを見分けられるようにします。配色の規則そのもの、つまり 2 つのテーマカラーと無彩色だけを使い、例外の色を安全に関わる表示の赤に限る規則は引き継ぎます。

派生の色は、主の色の明度だけを変えて作ります。値と、文字と背景のコントラスト比は次のとおりです。コントラスト比は WCAG 2 の相対輝度で計算し、どの組み合わせも 4.5 以上です。

| 用途 | 明るい配色 | コントラスト比 | 暗い配色 | コントラスト比 |
| --- | --- | --- | --- | --- |
| 上部の帯とタグの背景 (`--primary`) | `#20256e` | 白の文字で 13.54 | `#2a3184` | 白の文字で 11.22 |
| 帯のグラデーションの明るい側 (`--primary-light`) | `#363d94` | 白の文字で 9.33 | `#3d45a3` | 白の文字で 8.14 |
| 帯の縁 (`--primary-dark`) | `#12153f` | 白の文字で 17.43 | `#161a4a` | 背景にだけ使う |
| リンク (`--link`) | `#2f3aa6` | 白の背景で 9.22、下部の背景 `#dcdcdc` で 6.73、副の色の背景で 5.62 | `#a6aef0` | 本文の背景 `#1c1c1f` で 8.04、注意の背景 `#362e21` で 6.33 |
| リンクにポインターを重ねたとき・見出し (`--link-hover`・`--heading`) | `#20256e` | 白の背景で 13.54 | `#c8ccf4` | 本文の背景で 10.85 |
| 見出しの帯の文字 (`--bar-text`) | `#20256e` | 副の色の背景で 8.25 | `#e2c69c` | 背景 `#362e21` で 8.15 |

VST Compatible ロゴは、テーマカラーの規則の外に置きます。Steinberg が配布するファイルを、色と形を変えずに表示するためです。

## 文言の規則

画面と固定ページの文言は、配信プラグイン倉庫くんと同じ規則で書きます。主語を文頭に置き、利用者に求める行動は「〜してください」と書きます。日本語の文言は yomiyasu で推敲し、ほかの言語の文言は推敲した日本語の意味に合わせて書きます。

全ページ共通の注意書きは、次の 2 文です。

> このプラットフォームは、プラグインの規格の策定元や DAW の開発元と無関係の、非公式で無料のサービスです。各プラグインの安全性を保証しないので、個人の責任にもとづき注意して利用してください。

配布物を GitHub から直接ダウンロードすることは、注意書きには書かず、`/about` のページとダウンロードボタンの近くに書きます。

## VST の語の表示

[ADR 0004](../decisions/0004-vst-trademark.md) にしたがい、Steinberg VST usage guidelines の文面にすべてしたがいます。

| 項目 | 規則 |
| --- | --- |
| 表記 | 規格名は「VST® 3」と書く。® はページの中の VST の語の初出に付ける。2 回目からは「VST 3」と書く |
| VST Compatible ロゴ | VST の語を表示するページで、本文の中の「VST® 3」の表示の近くに置き、下部の商標の注記の横にも置く。ロゴは、掲載したプラグインが VST 3 に互換であることを示すためだけに使う。上部の帯・サービスのロゴのような、サイトの装飾やブランドには使わない。表示の高さは、ガイドラインの最小サイズの高さ 10 mm を 96 dpi で換算した 38 px |
| 注記 | VST の語を表示するページに「VST is a registered trademark of Steinberg Media Technologies GmbH.」と書く。翻訳しない |
| ロゴのファイル | Steinberg の VST 3 SDK の配布物に含まれる公式のファイルを使い、色・形・縦横の比を変えない。ガイドラインの最小サイズを守る |
| VST 3 での絞り込み | 配布物に VST 3 のバンドルを検出したプラグインだけを出す |
| 掲載の対象外の規格 | VST 2 と AAX の語を、規格の選択肢や表示に出さない |

ロゴを表示する場面は、規格の表示の有無で決まります。VST 3 のバンドルを検出したプラグインの詳細ページは、必ずロゴを表示します。ほかの規格だけのプラグインのページは、ロゴも注記も表示しません。

一覧と検索結果のページでは、検索フォームの規格の選択肢と、カードの規格のタグに「VST® 3」が出るため、ガイドラインの文面ではロゴが要ります。これらのページには、検索結果の見出しのすぐ下に、ロゴと説明の文を組にした 1 行を置きます。説明の文は、VST® 3 のタグを、配布物の中身の検査で VST 3 のバンドルを確かめたプラグインにだけ付けることを伝えます。ロゴだけを絞り込みの隣に置くと、閲覧者にロゴの意味が伝わらないためです。カードのタグの一つ一つには、ロゴを置きません。最小サイズを守ると、カードに収まらないためです。

ロゴの画像は、`/images/vst-compatible.png` と、暗い配色で使う反転版の PNG で配信します。本サービスのリポジトリには、ロゴの画像が Steinberg の商標であり、リポジトリのライセンスの対象外である旨を README のライセンスの節に書きます。

Steinberg が第三者のレジストリによるロゴの使用を認めない可能性は残ります。指摘を受けた場合は、ロゴの表示の取りやめ、あるいは VST の語の表示の取りやめで対応します ([ADR 0004](../decisions/0004-vst-trademark.md))。

## カテゴリ

カテゴリの値は次の 5 つです。

| 表示名 | `category` の値 |
| --- | --- |
| 音源 | `instrument`。MIDI の入力から音を作るもの |
| エフェクト | `effect`。音声の入力を加工するもの |
| 分析・メーター | `analyzer` |
| MIDI | `midi`。MIDI を加工するもの |
| ユーティリティ | `utility`。どれにも当たらないものと、推定できないもの |

カテゴリは、配布物のバンドルの中の情報から推定します。推定できない場合は作者の宣言ファイルの値を使い、それも無ければユーティリティにします。管理者は管理コマンドで直せます。推定の規則は [検査と同期](scanning.md) に記載します。

VST の名を冠したカテゴリは設けません。規格の区別は、カテゴリではなく規格の絞り込みで扱います。

## トップと検索

| 要素 | 内容 |
| --- | --- |
| 検索フォーム | キーワードの入力欄と、規格・OS・カテゴリの選択。規格の選択肢はすべて・VST® 3・CLAP・LV2・Audio Unit。OS の選択肢はすべて・Windows・macOS・Linux |
| 新着・更新 | 掲載中のプラグインのカード |

アーキテクチャは、Apple Silicon と Windows on Arm の利用者に必要な情報のため、カードに出します。アーキテクチャでの絞り込みは設けません。

## プラグインの詳細

詳細ページの表示は、プラグインの掲載状態で決まります。状態ごとの公開範囲は [データモデル](data-model.md) に記載しています。検査待ちのプラグインの詳細ページは、未登録のプラグインと同じく 404 を返します。変わる前の ID の詳細ページは、新しい ID の詳細ページへ 301 で転送します。

掲載中のプラグインの詳細ページは、上から順に次の要素で構成します。

| 要素 | 内容 |
| --- | --- |
| パンくずリスト | ライブラリとカテゴリ |
| 見出し | ロゴ・名前・カテゴリのタグ・規格のタグ・概要 |
| 止めた版の警告 | 管理者が止めた版、またはマルウェアを検出した版があるときだけ表示する |
| 説明の画像 | 作者が用意した画像 1 枚 |
| ダウンロードボタン | 案内する配布物ごとに 1 つ置き、GitHub の配布物へ直接リンクする。配布物名・サイズ・OS・アーキテクチャ・同梱する規格を添える |
| 基本情報 | 作者・規格・対応 OS・アーキテクチャ・ライセンス・バージョンと公開日・コミット SHA・GitHub リポジトリへのリンク・GitHub のリリース一覧へのリンク・ダウンロード数 (GitHub) と集計日 |
| 配布物と検査 | 案内する配布物ごとの名前・SHA-256・証明の検証の結果・MalwareBazaar の検査結果と検査日時・macOS 向けなら署名と公証の判定の結果。検出なしは安全の保証ではない旨 |
| 導入の案内 | 配布物は作者が GitHub で公開したものであること、導入前に作者の説明を読むこと、展開したバンドルを規格ごとのフォルダーに置くこと |
| 商標の注記 | VST 3 のバンドルを検出したプラグインだけ。「VST の語の表示」の規則にしたがう |
| 通報 | `/report` へのリンク |

VST 3 のバンドルを検出したプラグインでは、ページの中の VST の語の初出になる見出しの規格のタグに「VST® 3」と表示し、同じタグの行の最後に VST Compatible ロゴを置きます。ロゴをタグの間に挟まないのは、タグの高さをそろえて並べるためです。基本情報の規格の欄とダウンロードボタンの説明には「VST 3」と書きます。

配信プラグイン倉庫くんの「ビルドに使った OBS の版」は表示しません。ビルドに使った SDK の版も記録しないため、表示しません。

macOS の配布物を案内しない版では、macOS の配布物を案内していない旨を詳細ページに表示します。利用者が GitHub のリリースのページで macOS の配布物を見つけ、案内されない理由を知りたい場面があるためです。個々の理由と作者への指摘は表示せず、作者にだけ返します ([作者へのレビューの返し方](author-feedback.md))。

停止と掲載終了のプラグインの詳細ページの構成は、配信プラグイン倉庫くんと同じです。ロゴ・説明の画像・ダウンロードボタン・概要・配布物と検査の区画は表示せず、応答に `X-Robots-Tag: noindex` を付けます。

### 止めた版の警告

止めた版ごとに、版・配布物の SHA-256・本サービスで掲載していた期間・告知の文を表示します。表示する内容は、告知ページの同じプラグインの行と同じです。

## 告知ページ

告知ページ `/notices` は、止めた版の一覧を示します。侵害が起きたときに、影響を受けた版と期間を利用者に知らせるためのページです。項目と並び順は配信プラグイン倉庫くんと同じで、プラグイン・版・配布物の SHA-256・掲載の期間・告知の文を、止めた日時の新しい順に並べます。

## 検索エンジンと共有のときの表示

各ページの head に出す項目は、配信プラグイン倉庫くんと同じです。値を次のとおり替えます。

| 項目 | 内容 |
| --- | --- |
| title | 「<ページの名前> - <サイト名>」。詳細ページのページの名前は「<プラグインの名前> - オーディオプラグイン」で、画面の言語で表す。サイト名は en・pt-BR・es-419 では「Audio Plugin Soko-kun」、ja・zh-Hans・zh-Hant・ko では「音のプラグイン倉庫くん (Audio Plugin Soko-kun)」 |
| robots | 検索語 `?q=`・規格の絞り込み `?format=`・OS の絞り込み `?os=` を含むページは `noindex` にする |
| 構造化データ | トップに WebSite の JSON-LD を出す。`name` は「音のプラグイン倉庫くん」、`alternateName` は「Audio Plugin Soko-kun」。掲載中のプラグインの詳細ページには、SoftwareApplication の JSON-LD を出す |

title と description にプラグインの名前と概要を出すため、作者が名前に VST を含めると、検索結果に VST の語が出ます。検索結果にはロゴを出せません。作者に名前に VST を入れないよう案内する推奨 `plugin-name` は、この点でも必要です ([審査の基準](review-criteria.md))。

詳細ページの SoftwareApplication の JSON-LD のうち、配信プラグイン倉庫くんから替える値は次のとおりです。

| 項目 | 値 |
| --- | --- |
| `applicationCategory` | `MultimediaApplication` |
| `applicationSubCategory` | カテゴリの英語の名前 |
| `operatingSystem` | 対応 OS の英語の名前 |
| `softwareRequirements` | 同梱する規格の名前を並べたもの。例は `VST3, CLAP`。配信プラグイン倉庫くんの `OBS Studio <版>` は使わない |

## サービスのロゴ

配信プラグイン倉庫くんのロゴは、丸いバッジに図形で描いた「庫」の字で、払いの先がプラグの形です。本サービスのロゴは、同じ形の丸いバッジに図形で描いた「音」の字を置き、長い横線の左端をプラグの形にしたものです。主の色の地に副の色で描きます。原本は `src/web/logo.ts` の `LOGO_SVG` で、`public/logo.png` と `public/og.png` は `scripts/render-images.cjs` で作ります。字形を図形で描くのは、閲覧環境のフォントに左右されないためです。本サービスのロゴに VST Compatible ロゴや VST の語を含めてはいけません ([ADR 0004](../decisions/0004-vst-trademark.md))。

## プラグインの画像

ロゴと説明の画像の表示の規則は、配信プラグイン倉庫くんと同じです。ロゴはカードで 48 px 四方、詳細ページで 64 px 四方に収め、説明の画像は本文の幅に収めます。GIF は `<details>` で、利用者が開いたときだけ再生します。
