## 対応言語

| 言語タグ | 言語 |
| --- | --- |
| `en` | 英語 |
| `ja` | 日本語 |
| `zh-Hans` | 中国語簡体字 |
| `zh-Hant` | 中国語繁体字 |
| `ko` | 韓国語 |
| `pt-BR` | ブラジルポルトガル語 |
| `es-419` | 中南米スペイン語 |

上の 7 言語以外には対応しません。配信プラグイン倉庫くんと同じ 7 言語です。

## 言語の判定

Web カタログは、次の順に表示する言語を決めます。最初に対応言語のいずれかに決まった時点で判定を終えます。

| 順序 | 判定の材料 | 採る条件 |
| --- | --- | --- |
| 1 | クエリパラメーター `?lang=` | 値が対応言語の言語タグのいずれかと完全に一致する |
| 2 | cookie `lang` | 値が対応言語の言語タグのいずれかと完全に一致する |
| 3 | 要求ヘッダー `Accept-Language` | 下表の規則で対応言語のいずれかに対応づけられる |
| 4 | 上のいずれでも決まらない | 日本語 |

`Accept-Language` は、q 値の大きい順に言語タグを評価します。q 値が 0 の言語タグは使いません。言語タグは大文字と小文字を区別せず、次の規則で対応づけます。

| 言語タグ | 対応する言語 |
| --- | --- |
| `ja` で始まる | `ja` |
| `en` で始まる | `en` |
| `ko` で始まる | `ko` |
| `zh-TW`・`zh-HK`・`zh-MO` で始まる、または `Hant` を含む `zh` | `zh-Hant` |
| 上記以外の `zh` で始まる | `zh-Hans` |
| `pt` で始まる | `pt-BR` |
| `es` で始まる | `es-419` |
| 上記のいずれにも該当しない | 次の言語タグを評価する |

### cookie

`?lang=` で言語が決まり、その値が cookie の値と異なる場合に、cookie `lang` を書き込みます。

| 属性 | 値 |
| --- | --- |
| `Path` | `/` |
| `Max-Age` | 1 年 |
| `SameSite` | `Lax` |
| `Secure` | `ORIGIN` が `https:` で始まる場合だけ付ける |

応答には `Vary: Accept-Language, Cookie` を付けます。

### 言語の切替え

利用者は、全ページの上部にある言語の一覧から言語を切り替えられます。一覧のリンクは `?lang=` を付けた URL です。各ページは、対応言語の版を `hreflang` で示します。`x-default` は英語版を示します。`es-419` の版は `hreflang` の値を `es` にします。Google の `hreflang` が ISO 639-1 の言語と ISO 3166-1 の地域だけを扱うためです。画面の `lang` 属性は `es-419` のままです。

## 翻訳の対象範囲

| 対象 | 言語 |
| --- | --- |
| 画面の文言 | 対応言語のすべて |
| 固定ページの本文。`/about`・`/policy`・`/submit`・`/security`・`/report` | 対応言語のすべて。英語版を正とする |
| 利用規約とプライバシーポリシー。`/terms`・`/privacy` | 対応言語のすべて。日本語版を正とする |
| プラグインの概要 | 画面の言語へ機械翻訳して表示する。自動翻訳である旨を添え、詳細ページには原文を表示するリンクも添える。翻訳が無い場合は原文を表示する |
| 配布物名・リリース名・アーカイブの中のファイル名 | GitHub と配布物の原文のまま。翻訳しない。リリース名は画面に出さず、MCP の応答だけで返す |
| 規格名・OS 名・アーキテクチャの値 | 翻訳しない。「VST® 3」「CLAP」「LV2」「Audio Unit」の表記をすべての言語で同じにする |
| VST の商標の注記 | 翻訳しない。Steinberg のガイドラインが指定する英語の文「VST is a registered trademark of Steinberg Media Technologies GmbH.」をすべての言語でそのまま表示する ([ADR 0004](../decisions/0004-vst-trademark.md)) |
| MCP のツールの説明と応答 | 英語のみ。プラグインの概要は原文を返す |

正とする版以外の固定ページには、翻訳は参考である旨と、正とする版へのリンクを表示します。

商標の注記を翻訳しないのは、ガイドラインが注記の文言を指定しているためです。
